Acerca de Derixk Food

Plataforma integral de gestión gastronómica y punto de venta (POS) diseñada con arquitectura moderna de microservicios, frontend desacoplado y base de datos relacional de alta concurrencia.

Derixk Food nace como el proyecto integrador unificado para las cátedras de Tecnologías Web y Administración de Bases de Datos en la Universidad Técnica de Machala (UTMACH). Combina una interfaz visual de alto impacto inspirada en sistemas POS modernos con un motor transaccional robusto en PostgreSQL.

Misión y Gastronomía Ecuatoriana

El restaurante Derixk Food rinde tributo a la riqueza culinaria de la costa ecuatoriana (especialmente de la provincia de El Oro, Guayas y Manabí). La plataforma digitaliza desde la toma de comandas en sala hasta el despacho en cocina y la facturación, garantizando inventarios en tiempo real y mesas sin conflicto horario.

Arquitectura Técnica del Proyecto

Cumplimiento integral de los requerimientos de las asignaturas evaluadas.
Tecnologías Web
Frontend SPA • Angular 22
  • Standalone Architecture: Componentes desacoplados sin NgModules obsoletos.
  • Enrutamiento con Parámetros: Vistas dinámicas como /plato/:id.
  • Formularios Reactivos: Validación con ngModel y ngSubmit.
  • Pipes del Framework: currency, date, uppercase y Pipe personalizado estadoPedido.
  • Control de Sesión JWT: Interceptor HTTP inyector de Bearer Token y Role Guards de protección de rutas (RBAC).
API RESTful
Backend • Node.js + Express
  • Pool PostgreSQL: Conexiones concurrentes optimizadas con la librería pg.
  • Transacciones ACID: Ejecución controlada con BEGIN ... COMMIT / ROLLBACK en comandas.
  • Seguridad Criptográfica: Hashes salteados con bcryptjs y tokens JWT firmados.
  • Manejo de Errores: Captura de excepciones SQL y respuestas estructuradas en formato JSON.
  • Colección de Pruebas: Compatible con Thunder Client y Postman.
Base de Datos
PostgreSQL 16/18 • 3FN
  • Normalización 3FN: Integridad referencial con claves primarias y foráneas.
  • 3 Triggers Activos: trg_auditar_precio, trg_descontar_stock y trg_validar_reserva.
  • 2 Procedimientos Almacenados: sp_registrar_pedido y sp_cerrar_pedido.
  • 2 Vistas SQL de Negocio: v_ventas_por_mes y v_platos_mas_vendidos.
  • Concurrencia Pesimista: Bloqueos SELECT ... FOR UPDATE.
